\section{Discussion}
\label{sec:discussion}

\subsection{Implications for model developers}
\label{sec:implications}
Should model developers push models to use tools more than their own knowledge? Our results say this alone is not enough: Llama called the tool on every MedQA turn and still did worse. First, prefer tools whose output can be checked, such as code execution, and return error messages so the model can repair its call. Second, audit the tool interface itself: option order changed Qwen's tool use from almost never to always, and names and descriptions also mattered. Third, report evidence override next to accuracy, and train models on conflicts between the user and documents~\citep{li2026}. In high-stakes settings such as medicine, an assistant that agrees with a wrong user after checking a tool may do more harm than one without tools.

\subsection{What was promised, what was done, and what changed}
\label{sec:changes}
All promised metrics and significance tests were delivered. Changes, each with its reason (full list in Appendix Table~\ref{tab:changes}): (1) web search was run only on MedQA, because a 10-question MATH pilot returned mostly calculator pages and the models changed numbers in their queries; (2) on MATH, Python replaced the planned answer-only versus answer-plus-solution comparison, because it tests whether the model can check the claim itself; (3) the planned one- versus two-entry comparison is Exact versus T1; (4) the evidence-order ablation was not run, because the time went to the added tools (Exact, textbook, Python).

\paragraph{Limitations.} Tool effects are associations, not proof of cause: tool runs also add the menu and tool messages, and the model chooses when to use the tool. We test three 4-bit 3--4B models and only MATH Levels 1--2; MedQA results say nothing about clinical safety. P2 contains the P1 history; the 160-token limit cut off 9.3\% of mid-term replies; the parser rules were built on these replies and the unparsed replies were labelled only by an AI agent (Claude); and greedy decoding gives one reply per question. Future work: the evidence-order ablation, mandatory tool use, and why Llama ignores evidence.
